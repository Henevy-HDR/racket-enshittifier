Small, explicit controls

Make the rewrite yours.

Pick the transformation intensity, choose a seed, then decide how much breathing room the output gets.

A / Intensity

Five levels

From a light disturbance to the most complex supported rewrite. More intensity can add control-flow layers, forwarding helpers, and awkward names.

mildapocalypse
B / Text density

Same tokens. Different air.

At 0, spread whitespace into an unruly page. At 100, remove optional spaces and breaks. A fixed seed keeps every non-whitespace character unchanged.

( define ( f x )
  ( + x 1 ) ) → (define(f x)(+ x 1))
Required token separators and language syntax remain.

Repeat or regenerate

Enter a seed to reproduce a variant, or ask for another variation. Preview it first, then open it in a separate editable DrRacket window.

Get it into DrRacket

One install.
Then use the menu.

The plugin runs in DrRacket. The generated program opens separately, with the current language settings, so the source is easy to recover.

Download the package ↓
  1. 1
    Download the archive

    Save the package ZIP from this page.

  2. 2
    Install through DrRacket

    Choose File → Install Package… and select the ZIP.

  3. 3
    Restart and transform

    Open Enshittify source… from the active language menu.

  4. 4
    Preview, then open a copy

    Change settings or generate another variant before opening the editable result.

What it safely understands

Conservative by design.

It prioritizes known syntax over rewriting everything. If the engine cannot safely classify a form, it leaves that code alone or skips the containing function.

✓

Teaching-language focus
BSL and its variants, plus a restricted first-order subset of other supported languages.

✓

Reader-aware whitespace
Strings, comments, escaped identifiers, character literals, and reader directives are protected.

i

Not a universal equivalence proof
Source-location inspection, resource limits, timing, replaced primitives, and unsupported forms remain outside the guarantee.
